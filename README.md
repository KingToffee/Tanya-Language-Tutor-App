# Tanya — AI Assistant & Language Tutor

**Tanya** is an Android AI assistant for everyday conversations and learning. Switch to **Frau Christa** to practice German.

### Features
- Chat with Tanya in English or practice German with Frau Christa
- Spoken responses and voice input
- Conversation history saved on your device
- Optional Google sign-in
- App update checks

### Download and install
1. Open **[Releases](https://github.com/KingToffee/Tanya-Language-Tutor-App/releases)**.
2. Download the latest **signed APK** when available.
3. Open the APK on your Android device and follow the installation prompts.

**Requirements:** Android 8.0 or newer. An internet connection is required for AI responses; spoken responses use on-device voices.
